# CareerPilot AI App & Backend

Mobile Flutter application & FastAPI REST backend service for the **CareerPilot AI Dashboard**.

- **Frontend**: Flutter cross-platform mobile & web client (`lib/`).
- **Backend**: FastAPI Python REST service (`backend/`).

For full project documentation, API reference, setup guides, and APK download instructions, please refer to the main repository [README.md](../README.md).
